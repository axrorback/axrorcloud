# Qoʻllanma

Birinchi navbatda saytdan shaxsiy autentifikatsiya tokeningizni oling:

axrorcloud --auth <AUTENTIFIKATSIYA_TOKENI>

Mahalliy serveringizni internetga chiqaring:

axrorcloud --port <SIZNING_PORTINGIZ>

Shuningdek, siz maxsus subdomenni ham belgilashingiz mumkin:

axrorcloud --port <SIZNING_PORTINGIZ> --sd <SIZNING_SUBDOMENINGIZ>
Tunelni CTRL + C tugmalarini bir vaqtda bosish orqali toʻxtatishingiz mumkin.
